# Responsive

Mobile is the primary experience.

Breakpoints:

```text
mobile: < 640px
tablet: 640-1023px
desktop: 1024-1439px
wide: >= 1440px
```

Designs must not simply shrink desktop layouts. Customer card and POS flows should be comfortable on phones, tablets, and desktops.

Core viewport checks:

- 320px
- 375px
- 390px
- 430px
- 768px
- 1024px
- 1280px
- 1440px

Avoid horizontal scrolling except for data tables where horizontal overflow is deliberate and accessible.
