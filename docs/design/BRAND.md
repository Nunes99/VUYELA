# Brand

## Name

```text
VUYELA
by LEMOTE
```

LEMOTE means **Leader of Modern Technology**.

## Meaning

VUYELA represents returning:

```text
Customer
Purchase
Points
Return
New purchase
Growth
```

## Core Messages

Slogan:

```text
Volte. Ganhe. Cresca.
```

Positioning:

```text
Cada compra cria uma razao para voltar.
```

Business message:

```text
Clientes que voltam.
Negocios que crescem.
```

## Cultural Direction

The interface should feel modern and Mozambican. Use original geometric patterns inspired by capulana composition as subtle texture, usually around 3-8% opacity.

Do not copy protected patterns, decorate with the Mozambique flag as the main motif, or reduce legibility.
